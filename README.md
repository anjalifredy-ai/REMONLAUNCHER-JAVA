# REMONLAUNCHER-JAVA
RemomLauncher - Advanced Minecraft: Java Edition Launcher for Android. Horizontal UI, Modrinth &amp; CurseForge integration, custom optimized engine support for Vanilla/Fabric/Forge/NeoForge/OptiFine, profiles, skins, controls, server hosting features. Inspired by PojavLauncher &amp; Battly Launcher.
